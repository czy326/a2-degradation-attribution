### 1.1 `SD_real` 是怎么估的（LS 无种子，只有这一条路）

L1 只有 **1 个种子**，估不出种子水平 SD。预注册（§3.2、§7.4）定的办法是：
用**三个不同的退化实现**（`l1X_` / `l1Z_` / `l1Y_`）各跑一遍 **ref 端点**，
用它仨的离散度当"实现噪声地板"：

| 臂 | 三次实现的 ref mAP5095 | SD_real |
|---|---|---|
| `dior_l1_A` | 0.27298 / 0.27113 / 0.27141 | **0.00100** |
| `dior_l1_B0` | 0.25727 / 0.25738 / 0.25865 | **0.00077** |

三次重复的极差只有 0.0019 / 0.0014 —— 说明**评测管线本身是稳的**，
`Δ = +0.0157` 不是实现抖动造出来的。

### 1.2 `SNR_imp` 依赖的导入假设（照抄预注册 §3.2，必须写进论文）

1 个种子给不出种子 SD ⇒ 用 AI-TOD 上实测的 `SD_imp = 0.00141`
（`_mde_check.py` §2.2）当作"效应测量的种子噪声"：
`MDE_imp = 2.571 × 0.00141 / √6 = 0.001480`，`SNR_imp = 0.01571 / 0.001480 = 10.62`。

**这是一条假设，不是 DIOR 上的实测**。它的作用是回答"这个效应量级放大了种子数以后还测得出来吗"。
备查：AI-TOD 上同样的锚点效应是 `Δ = +0.00729`，`SNR_imp = 4.93`。

## 2. 与 AI-TOD 的横向对照（只比"量级"，不比绝对值）

| 量 | AI-TOD（`_mde_check.py` §2.2） | **DIOR L1** | 比 |
|---|---|---|---|

这句话按 L0 §3.1 的纪律只能写成"边界检验的正面证据"，
**不能**写成"跨数据集复现了主结论"（尺度分布不同）。

## 3. ★ 必须记下的反向发现：`Δ(A − B0)` **随退化轴变号**

16 个条件的逐点对照（`dior_l1.json` 的扫描切片）：

| 部署条件 (blur, noise) | A | B0 | **A − B0** |
|---|---|---|---|
| (0.0, 0.003) ← **ref / 判据锚点** | 0.2730 | 0.2573 | **+0.0157** |
| (0.2, 0.003) | 0.2723 | 0.2582 | +0.0141 |
| (0.6, 0.003) | 0.2713 | 0.2597 | +0.0116 |
| (1.2, 0.003) | 0.2714 | 0.2578 | +0.0136 |
| (2.0, 0.003) | 0.2657 | 0.2565 | +0.0092 |
| (2.4, 0.003) | 0.2636 | 0.2572 | +0.0064 |
| (0.2, 0.012) | 0.2675 | 0.2589 | +0.0086 |
| (2.0, 0.012) | 0.2593 | 0.2579 | +0.0014 |
| (0.2, 0.024) | 0.2588 | 0.2566 | +0.0022 |
| (2.0, 0.024) | 0.2515 | 0.2499 | +0.0016 |
| (0.0, 0.096) | 0.1762 | 0.1831 | **−0.0069** |
| (0.2, 0.096) | 0.1703 | 0.1814 | **−0.0111** |
| (0.6, 0.096) | 0.1721 | 0.1838 | **−0.0116** |
| (1.2, 0.096) | 0.1665 | 0.1788 | **−0.0123** |
| (2.0, 0.096) | 0.1561 | 0.1678 | **−0.0117** |
| (2.4, 0.096) | 0.1484 | 0.1597 | **−0.0112** |

读法：

- `noise ≤ 0.024` 的 **10 个条件全为正**，且随噪声升高单调衰减（+0.0157 → +0.0016）。
- `noise = 0.096` 的 **6 个条件全为负**，量级 −0.0069 ~ −0.0123。
- 两条曲线在 `noise ∈ (0.024, 0.096)` 之间**交叉**。

这与本课题既有的结论**完全一致**：`tv_factor2x2` / §1.2 早已证明
"效应曲线会随工作点变号，对其取平均是构造出来的"。
L1 的判据是在**预注册的 ref 端点**上定的（+0.0157），所以判"放行"是合规的。
但这条交叉是**实质性的科学结果**，必须在论文里作为"适用边界"的证据写出来：
**"训练覆盖退化"带来的收益，在退化强度超过某一点后转为代价。**

⚠️ 这条只由 **1 个种子 × 1 个架构 × 1 个数据集** 给出，交叉点的位置不可靠，
下一步（L2）用 6 个种子把交叉点定出来。

## 4. 子集审计（`dior_l1.json` 的 `subset`）

| 层 | 图数 | 目标数 | 目标/图 | 中位短边 | 可用桶(n≥150) |
|---|---|---|---|---|---|
| 池（md5 前 2000） | 2,000 | 10,519 | 5.26 | 30.0 px | 7 |
| 训练（75%） | 1,500 | 7,986 | 5.32 | 30.0 px | 7 |
| 扫描（评测） | 500 | 2,533 | 5.07 | 31.0 px | **6** |

- 取样规则 = **`md5(文件名)` 确定性乱序取前 2000**（`DIOR_L1_PREREG.md` §7.4）。
  实测中位 30 px、每图 5.26 目标，与整档（28 px / 5.56）的偏离在 §7.4 预期范围内（md5 方案 +2.7 pp）。
- 扫描段 500 图 / 2,533 目标 / **6 个可用桶** —— 达到 §7.4 设定的目标（5 个以上）。
- 评测是**逐桶**的（`n < 150` 的桶不计入 mAP5095），这是既有口径。

**已查明（2026-10-17 05:2x，AN-4）**：训练时 ultralytics 报 `Using 1499 train, 500 val images`，
但视图目录里是 1500 张。根因是**断点续跑与「先写图、后拷标签」之间的时序缝隙**：

```
dior_l1.py::build_view
  if os.path.isfile(dst) and os.path.getsize(dst) >= 5120: return 0   ← 先判「图已存在」就跳过
  cv2.imwrite(dst, out)                                              ← 先写图
  if os.path.isfile(lp): shutil.copyfile(lp, ...)                     ← 后拷标签
```

进程若在 `imwrite` 之后、`copyfile` 之前被中断，重启时因 `dst` 已存在而**跳过整条**，标签永久缺失。
实测：`dior_l1_A/images/train` 1500 张、`labels/train` 1499 个，缺的是 **`00688.png`**，
而源 `dior/labels/train/00688.txt` 与 `dior_l1_B0`、`dior_l2_B2`、`dior_l2_D0` 三份视图的同名标签**都在**
⇒ 只有 `dior_l1_A` 这一份、只有这一张，符合「唯一一次被打断的时点」。

**影响**：1 / 1500 = 0.067%，对 `Δ` 的影响远小于实现噪声地板（0.00100 mAP），**不影响判决**。
`dior_l1_A` 的评测切片（500 图）无缺口，`val` 侧 500/500 完整。

**处置**：① 代码已修（跳过分支里只在标签确实缺时补拷一次，不重算图像，已 `py_compile` 通过）；
② **已有视图不补** —— 补上 `00688.txt` 会让下次重跑得到 1500 图、与已缓存的 1499 图产物不一致，
反而制造溯源混乱；③ 后续任何视图（含 SODA-L2 续跑）不会再出现此缺口。

## 5. 事先声明的局限（照抄预注册 §6，一条不减）

1. L1 只有 **1 个种子**，给不出种子水平 SD；`SNR_imp` 依赖 §1.2 的导入假设。
2. L1 只在 **2,000 张子集**上做，不是全量 23,463 张 ⇒ 训练集更小，
   **绝对 mAP 不可与 AI-TOD 横向比**（A=0.273 高是因为 DIOR 目标大得多），L1 只做**相对对照**。
3. DIOR 中位 30 px（AI-TOD 10 px）⇒ 这本就是**跨尺度边界检验**，
   效应更大或更小都可归因于尺度，而不是"复现失败"。
4. L1 不含架构轴（仍为 YOLOv8n）。
