# 噪声 / JPEG 解耦实验 —— 预注册判决规则

**落盘时间：2026-10-16 17:04（实验启动后、结果产生前）**
实验 ID：tv_factor（2 臂 × 6 种子 × 16 条件）
数据文件：`tv_sweep.jsonl`（新臂并入后共 576 行 = 6 臂 × 6 种子 × 16 条件）
分析脚本：`tv_factor2x2.py`（规则写定后不再改口径）

---

## 1. 设计（已固定，不可事后更改）

宽模糊层 2×2，**四格 blur 范围严格相同** = U(0.20, 2.00)：

| 格 | 臂 | noise | JPEG | 状态 |
|---|---|---|---|---|
| (0,0) | `tv_D0` | 无 | 无 | 已有（复用，不重训） |
| (1,0) | `tv_N2` | **有** | 无 | 新增 |
| (0,1) | `tv_J2` | 无 | **有** | 新增 |
| (1,1) | `tv_B2` | 有 | 有 | 已有（复用，不重训） |

为什么不补窄模糊层：窄层 A 格 blur 是 (0.00,0.00)、B0 格是 (0.00,0.05)，四格不在同一
blur 水平 ⇒ 拆出的效应会混进 0.05 的模糊差。宽层四格 blur 严格一致，是唯一能做
**无混淆** 2×2 的一层。

种子：2026–2031（n=6，df=5，95% 临界 |t| = **2.571**）。

## 2. 估计量（沿用 §7 口径 ③，不换）

- `M_c(det)` = 检测器在部署条件 c=(blur, noise) 上的 mAP50-95
- `Z_c(det)` = `M_ref(det) − M_c(det)`，ref = 最轻条件 (blur=0.0, noise=0.003)
- `closure_c(X)` = `(Z_c(D0) − Z_c(X)) / Z_c(D0)`
- 臂间检验在**种子水平**配对（同一检测器、同一条件）

## 3. 主终点（primary endpoint）

**四个简单对照**在 **16 个部署条件**上的「同号条件数 + 显著条件数」：

| 对照 | 含义 |
|---|---|
| `N2 − D0` | 仅加噪声 → 效应 |
| `J2 − D0` | 仅加 JPEG → 效应 |
| `B2 − D0` | 两者都加 → 合效应 |
| `B2 − N2` | 在已有噪声上再加 JPEG → JPEG 的增量 |
| `B2 − J2` | 在已有 JPEG 上再加噪声 → 噪声的增量 |

**不**对逐条件效应取平均当作"总效应"（§1.2 已证明该曲线随工作点变号，取平均是构造出来的）。

## 4. 判决规则（结果出来前写定）

记 `sig(X)` = 该对照在 16 条件里 |t| > 2.571 的条件数，`same(X)` = 同号条件数。

| 判决 | 触发条件 |
|---|---|
| **H_noise（噪声主导）** | `sig(N2−D0) ≥ 6` **且** `same(N2−D0) ≥ 12` **且** `sig(J2−D0) ≤ 2` |
| **H_jpeg（JPEG 主导）** | `sig(J2−D0) ≥ 6` **且** `same(J2−D0) ≥ 12` **且** `sig(N2−D0) ≤ 2` |
| **H_joint（两者都实质贡献）** | `sig(N2−D0) ≥ 6` **且** `sig(J2−D0) ≥ 6`，且二者 `|Δ|` 中位数之比落在 [1/2.5, 2.5] 之内 |
| **H_null（都无效）** | `sig(N2−D0) ≤ 2` **且** `sig(J2−D0) ≤ 2` |

以上四条互斥；若不落入任何一条 ⇒ 报 **"未判死"**，如实说明，不硬套结论。

## 5. 次要终点（描述性，不用于判决）

1. **clean 端能力代价**：ref 条件上各格 mAP 相对 D0 的百分比。
2. **closure**：`cl(N2)` / `cl(J2)` / `cl(B2)` 在 5 个部署条件上的值。
3. **clean 端剂量-响应斜率**（noise=0.003，对 blur 线性拟合，逐种子再 t 检验）。
4. **交互项** `E_inter = B2 − N2 − J2 + D0`。

## 6. 反向验证（负向对照）

- 若 `N2` 与 `J2` 的 16 条件结果**逐条件一致**（差值均 < 1e-6）⇒ 判为**实现错误**，
  停用本实验并检查退化算子开关，不得当作"两者等价"的证据。
- 若 `tv_N2`/`tv_J2` 的 clean 端 mAP 与 `tv_D0`/`tv_B2` 落在同一"能力档"内
  （即噪声/JPEG 未造成预期代价）⇒ 需先核对视图是否真的带上了噪声/JPEG
  （用 `_flag_probe.py` 复验），再谈效应。

## 7. 事先声明的局限（无论结果如何都要写进论文）

1. 只在**宽模糊层**做 2×2 ⇒ 严格地说，结论是"在宽模糊训练设定下"的分解；
   推广到窄模糊依赖 §7 已建立的「模糊范围无效」。
2. 仍为单数据集（AI-TOD）+ 单架构（YOLOv8n）。
3. 同引擎各种子共享视图（视图与种子无关）⇒ 该 t 检验反映**训练随机性**，
   不是数据集抽样，不可外推为"数据层面显著性"。
4. 噪声算子含信号相关散粒噪声 + 读出噪声两项；JPEG 质量在 U(30,95) 随机。
   "噪声"与"JPEG"各自内部仍有参数维度未扫（留作后续）。
