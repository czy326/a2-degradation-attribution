# DIOR L2 —— 预注册判决规则（多种子 × 多臂）

日期 2026-10-16 21:20 ｜ 上游 `DIOR_L1_PREREG.md`（L1 判决：**放行 L2**，`DIOR_L1_VERDICT.md`）
本文件在任何 L2 训练产生之前写定 ｜ 脚本 `dior_l2.py` ｜ 缓存 `dior_l2.jsonl`

---

## 0. 一句话

**L1 回答了"做不做得出来"，L2 只回答"那个数稳不稳、边界在哪"。**
L2 **不改** L1 的池、划分、视图、条件网格里的任何一个字，只做两件事：**加种子（1 → 6）、加臂（2 → 4）**。
主终点仍是那个 `Δ(A−B0) @ ref`，只是从 1 个点变成 6 个点的 95% 区间。

---

## 1. 这一步回答什么（只回答这三件，不回答别的）

`DIOR_L1_VERDICT.md` §6 已写死 L2 的三个待答问题：

| # | 问题 | L1 为什么答不了 |
|---|---|---|
| ① | `Δ` 的**种子水平置信区间**（不再是导入假设） | L1 只有 1 个种子 |
| ② | `Δ` **随退化轴变号**的交叉点在哪 | 1 个种子 × 1 个架构定不了交叉点位置 |
| ③ | 逐桶 AP 在 DIOR 的**大目标端是否衰减** | L1 只报了汇总 mAP |

**L2 不回答**：现象在别的数据集/架构上是否复现（那是 SODA-A 与架构轴的事）。
**L2 不重做**：AI-TOD 上已完成的噪声/JPEG 解耦（`FACTOR_VERDICT.md`，命中 `H_joint`）。
DIOR 上的 4 臂**不做**完整 2×2 解耦 —— 只把 `B2`/`D0` 当作"宽模糊层的两个端点"用来定位交叉点。

## 2. 设计（固定，不可事后更改）

| 项 | L1 | **L2** | 说明 |
|---|---|---|---|
| 图像源 | `DIOR/images/train`（`train.zip`，5,862 张） | **同 L1** | 不用 `val.zip`（见 §5.1） |
| 池 | `md5(文件名)` 乱序取前 **2,000** | **同 L1** | 逐字节同一批图 |
| 划分 | 75% / 25% ⇒ 1,500 train / 500 scan | **同 L1** | 同一顺序 ⇒ 同一划分 |
| 扫描切片 | `files[1500:][:500]` | **同 L1** | 2,533 目标 / 6 个可用桶 |
| 条件网格 | 16 条（blur × noise） | **同 L1** | 逐字复制 `tv_sweep.collect()` |
| 退化口径 | `shot=False`、`resample="area"`、jpeg | **同 L1** | — |
| SR 引擎 | BSRGAN ×4 | **同 L1** | — |
| 训练 | YOLOv8n，30 epoch，imgsz 800，batch 8 | **同 L1** | — |
| 种子 | 1 个（2026） | **6 个（2026–2031）** | ★ 唯一变化之一 |
| 臂 | 2 个（A / B0） | **4 个（A / B0 / B2 / D0）** | ★ 唯一变化之二 |
| 地板复现 | ref 条件另用 2 个 `tag_base` 各评一次 | **同 L1** | 每次训练各 3 个实现 |

**臂的定义**（与 `tv_sweep.TRAIN_ARMS` 逐字一致）：

| 臂 | blur σ ~ U | noise | JPEG | 角色 |
|---|---|---|---|---|
| **A** | (0.00, 0.00) | ✗ | ✗ | 无退化锚点 |
| **B0** | (0.00, 0.05) | ✓ | ✓ | 窄模糊层；L1 的主对照 |
| **B2** | (0.20, 2.00) | ✓ | ✓ | 宽模糊层（有噪声/JPEG） |
| **D0** | (0.20, 2.00) | ✗ | ✗ | 宽模糊层（无噪声/JPEG） |

### 2.1 ★ 视图复用：A / B0 用的是 L1 的**同一批视图文件**

A 与 B0 的视图 tag **沿用 L1 的 `dior_l1_A` / `dior_l1_B0`**，因为退化的随机数种子是
`arm_rng(stem, tag)` —— **换 tag 就会换 LR 视图**，那就不再是"逐字节相同"，L1 的单种子点也就
不能并进 L2 的 6 种子集合里对照。运行目录（`runs/`）与检测器名另用 `dior_l2_<臂>_s<种子>`。
⇒ L1 的 `Δ = +0.01571` 因此可以**当作 L2 的第 7 个参照点**（但它仍是 1 个种子，
不进 6 种子的均值/SD）。

### 2.2 本次先跑的臂（**范围声明**，不是改判据）

L2 的完整定义是 4 臂 × 6 种子。实际执行分两块：

| 块 | 内容 | 状态 |
|---|---|---|
| **核心块** | 臂 **A / B0** × 6 种子 × 16 条件（+地板 2 条） | **先跑** |
| 扩展块 | 臂 **B2 / D0** × 6 种子 × 16 条件 | 核心块跑完再决定 |

理由：§1 的三个问题里，①②③ **全部**由 A/B0 两臂回答；`B2`/`D0` 只是把交叉点从"两条曲线"
变成"四条曲线"，属于**描述性加强**，不承担判决。**这个拆分写在跑之前**，不是看到结果再切。

## 3. 判据（结果产生前写定，不许事后改判）

### 3.1 主终点：种子水平的 `Δ(A − B0) @ ref`

对每个种子 `s`：`Δ_s = mAP_A(ref, s) − mAP_B0(ref, s)`，两臂同种子共用同一 `tag`
⇒ 逐图看到**完全相同**的退化实现（与 L1 同纪律）。
汇总 `n = 6`：`mean`、`SD(ddof=1)`、`95% CI = mean ± 2.571 × SD / √6`（`t_crit(df=5)`）、
单样本 `t = mean / (SD/√6)`。

| 判据 | 阈值 | 含义 |
|---|---|---|
| **① 复现** | `95% CI` **不含 0** 且 6/6 同号且 `mean > 0` | 现象在 DIOR 上稳定复现 |
| **② 等效性（TOST）** | `CI ⊂ (−0.05, +0.05)` | 与 AI-TOD 同口径的 ±0.05 等效界 |
| **③ L1 点是否在区间内** | `Δ_L1 = +0.01571 ∈ 95% CI` | 单种子点与 6 种子区间自洽 |
| **④ 可测性** | `MDE_seed = 2.571 × SD / √6`，需 `MEAN > MDE_seed` | 与 L1 不同，这里 SD 是**实测**的，不是导入的 |

### 3.2 判决表（分支顺序在代码里写死，不许改序）

```
if ① 成立 (CI 不含 0 ∧ 6/6 同号 ∧ mean>0)
        → ★ 复现：主张可升格为跨数据集机制（SCALEUP_GATE 结局 Ⅰ）
elif CI 含 0 且 MDE_seed < 0.005
        → ⛔ 真否证：效应在 DIOR 上确实小于可测下限（写清这是现象否证，不是功效问题）
elif CI 含 0 且 MDE_seed ≥ 0.005
        → ⚠ 功效不足：**不许写"否证"**，必须报 MDE 与"要到多少种子才可测"
elif mean < 0 且 CI 不含 0
        → ★ 反向：训练覆盖退化在 DIOR 上有净代价 ⇒ 写"适用边界"（与 L1 §3 的变号发现同源）
else
        → ⚠ 未判死也未判活，需补种子或核测量管线
```

★ **② 等效性不参与分支**，只作为报告项：Cochrane 纪律 —— 不显著 ≠ 等效，
两者必须分开写（"未测到差异"与"证明无差异"是两句话）。

### 3.3 次要终点（**描述性，不参与判决**）

1. **交叉点**：对每个种子，把 16 个条件的 `Δ` 按 `noise` 排序，报**符号变化所在区间**；
   6 个种子给出 6 个区间 ⇒ 报**区间的并集/交集**，不报点估计。
   （L1 单种子：`noise ≤ 0.024` 全正、`noise = 0.096` 全负 ⇒ 交叉在 (0.024, 0.096)。）
2. **尺度分层**：逐桶 `Δ`（用 `eval_arm` 返回的 `bins[label].a5095`），
   报 `Δ` 随桶中位尺寸的趋势，重点看 `24-32` / `32-64` 桶是否衰减。
3. **种子噪声对照**：`SD_seed(Δ)` vs AI-TOD 实测 `0.00141`（`SCALEUP_GATE.md` §2.2）。
4. **地板**：仍报 `SD_real`（每臂 3 个退化实现的 ref 极差），用于确认 L1 的 `SD_real ≤ 0.00100` 可复现。

## 5. 事先声明的局限（无论结果如何都要写进论文）

1. **不用 `val.zip`**：L2 的池仍只来自 `train.zip`（5,862 张里的 2,000 张）。
   理由是与 L1 严格连续（同一批图、同一划分），代价是 DIOR 的 5,863 张 val 在 L2 里没被用。
   ⇒ 若要主张"用满 DIOR"，需另立一次独立检验，**不能事后把 val 塞进 L2 的池**。
2. **子集不是全量**：2,000 / 11,725 ⇒ 绝对 mAP 不可与 AI-TOD 横向比，只做**相对对照**。
3. **DIOR 中位 30 px（池）/ 31 px（扫描）**，与 AI-TOD 的约 10 px 不同尺度带
   ⇒ 效应更大或更小都可归因于尺度，不是"复现失败"。
4. **不含架构轴**：全为 YOLOv8n。
5. **`B2` / `D0` 若未跑**，交叉点只有 A/B0 两条曲线（介于 16 条件的 `blur∈{0.0,0.2}` 之间）。

### 6.3 2026-10-16 21:5x —— 次要终点「交叉点」的**呈现逻辑**修正（§3 阈值未动）

跑前离线自测（`_selftest_l2_verdict.py`，5 个合成场景走通 `verdict()` 全路径）时，
抓到原实现的一处**逻辑缺陷**：变号区间的构造不检查**单调性**。

原实现：
```python
for c in ns:                       # ns = noise 升序
    if min(bynoise[s][c]) > 0: last_pos = c
    elif first_nonpos is None: first_nonpos = c
```
这在"先非正、后全正"的符号模式（**非单调**，Δ 在 noise 轴上变号 ≥2 次）下，
会产出 `last_pos > first_nonpos` 的**倒挂区间**（自测实测：`[0.024, 0.003]`），
并被当成合法区间写进 `dior_l2.json` 的 `crossover.intervals`。

修法（三处）：
1. 只有在**全正组全部排在非正组之前**时才产出区间；
2. 非单调的种子**不进** `cross`，落到新的 `crossover.nonmono_seeds`，
   并在 stdout 打印逐 noise 的「组内全正?」标记；
3. `_cross_out()` 增加断言性约束：写出去的每个区间必须 `lo < hi`；
   交集为空时 `ci_lo` / `ci_hi` 写 `None`，不许把颠倒的两个数当区间写出去
   （§3.3：报区间的并集/交集，**不报点估计**——倒挂的两个数连"区间"都不是）。

**这一条不改 §3 的任何阈值**，只改 §3.3 次要终点的呈现。它同时**放宽了报告口径**：
若真数据上出现非单调，论文里必须写「符号随噪声非单调」，**不许**折成一个交叉点。

### 6.4 2026-10-17 01:25 —— 次要终点「地板」的**量标错**，修正（§3 阈值未动）

**怎么发现的**：核心块（01:14 完成）的真实产物里，【地板】段报 `A=0.00185 / B0=0.00307`，
**比 L1 报的 `SD_real ≤ 0.00100` 大了 2–3 倍**。L1 与 L2 用的是同一批视图、同一批图、
同一划分、同一 seed，两边的实现噪声不该差这么多 ⇒ 回头读代码发现是**量标错**：

```python
reps = [m(a, s, TB_MAIN, *REF) for s in seeds]        # ← s 遍历的是**种子**
floors[a] = float(np.std(reps, ddof=1))
```
这是在算「ref 条件的 mAP 在 **6 个种子**之间的 SD」，却被写成 `SD_real`（退化实现噪声）。
§3.3 第 4 条要的是 **L1 同口径**的量：同一 (臂,种子) 下，用 `[TB_MAIN] + TB_REPS`
= **3 个 `tag_base`** 各评一次得到的极差/SD。

**修法**：逐 (臂,种子) 用那 3 个 tag_base 算 `SD_real`，报**逐种子的 6 个值 + max + mean**，
并额外打印"ref 条件下 mAP 的种子间 SD"作为**另一个量**对照。
JSON 新增 `floor_max` 与 `floor_by_seed`（旧字段 `floors` 语义改为逐臂 max）。

**这一条不改 §3 的任何阈值**，只把 §3.3 第 4 条报的量改对。
核心块那次输出的该项**是错的，不要引用**；最终值以扩展块跑完后由
`_regen_l2_verdict.sh` 用当前代码重出的那份为准（原产物备份为 `dior_l2.json.pre-regen`）。
